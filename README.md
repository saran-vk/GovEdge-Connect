# S5 Mini Project — Multilingual Speech-to-Welfare Assistant (Week 1)

Voice + text assistant for e-Governance welfare schemes. **Week 1** builds two
parallel prototype tracks plus a shared interface contract.

- **Track A (NLU, RAG & edge)** — lead: Saran V (7376242AD294)
- **Track B (Speech & language AI)** — lead: Sanjay Rathinam M N (7376242AD288)

## Quick start (Linux / macOS / Windows)

```bash
# 1. one-time: create .venv and install deps
bash scripts/setup_venv.sh          # Linux/macOS
# OR: powershell -ExecutionPolicy Bypass -File scripts/setup_venv.ps1  # Windows

# 2. activate the venv
source .venv/bin/activate           # Linux/macOS
# OR: .\.venv\Scripts\Activate.ps1  # Windows

# 3. one-shot week-1 run
bash scripts/run_all.sh             # Linux/macOS
# OR: powershell -ExecutionPolicy Bypass -File scripts/run_all.ps1  # Windows

# or step-by-step:
python -m track_a.build_index          # Track A: corpus -> chunks -> ChromaDB
python -m track_b.synth_audio          # Track B: synthesize en/hi/ta clips
python -m track_b.benchmark            # Track B: WER/CER baseline
python -m track_b.profiler             # Track B: NMT/TTS latency profile
python -m demo.end_to_end --text "Am I eligible for PM Kisan?"   # full demo with response

# tests (offline)
python -m pytest track_a track_b -v
```

All model weights/caches stay in `.hf_cache/` inside the repo — nothing is
written to your global HuggingFace cache.

## Notes / known limitations

- Embeddings use **BAAI/bge-m3** (open, multilingual, no auth required) instead
  of the gated `ai4bharat/indic-bert`. Falls back to `all-MiniLM-L6-v2` if
  bge-m3 fails to load.
- ASR uses Whisper **medium** model with `initial_prompt` hinting for better
  Indic language recognition. To use the RTX 4050: set `track_b.asr.device: cuda`
  and `compute_type: float16` in `config/settings.yaml`.
- NMT uses `ai4bharat/indictrans2-en-indic-1B` (gated, needs `HF_TOKEN` env var)
  with automatic fallback to `facebook/nllb-200-distilled-600M` (non-gated).
- The corpus includes 8 seed fact sheets (PM-KISAN, Ayushman Bharat, PMAY,
  TN welfare, MGNREGA, Ujjwala, Jan Dhan, Sukanya Samriddhi). Real e-Gov PDFs
  go in `track_a/data/raw/` (pdfplumber extracts them).
- Project is installable: `pip install -e .` (via `pyproject.toml`).
